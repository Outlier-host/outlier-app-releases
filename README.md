# Outlier — Mac App Releases

**Stable link (never changes):** https://outlier.host — its Download button always
points at the newest build.

**Stable release page (never changes):**

```
https://github.com/Outlier-host/outlier-app-releases/releases/latest
```

Always opens the newest release; the Mac download is the `Outlier-<version>-arm64.dmg`
file there. Each release's DMG name includes its version, so a direct
`…/releases/latest/download/…dmg` link only works until the next release — link one of
the two addresses above instead.

---

**Requirements:** macOS 26 or later (a free update), Apple Silicon (M1 or newer).

**Install:** Download the DMG, double-click to mount, drag `Outlier.app` to
`Applications`, eject the DMG.

---

See https://outlier.host for full product info.
